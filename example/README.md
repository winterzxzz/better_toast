# better_toast example

A showcase app for [better_toast](https://pub.dev/packages/better_toast).
It demonstrates every toast type, rich content with actions, update-by-id,
promise toasts, a custom builder, stacking, and live switching of position,
animation, stack mode, look (default, glass, bold), dark mode and RTL.

```sh
cd example
flutter run
```

The interesting code is in [`lib/main.dart`](lib/main.dart).
